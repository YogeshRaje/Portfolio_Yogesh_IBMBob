# ══════════════════════════════════════════════════════════════════════════════
#  SECTION 1 — RUNTIME REQUIREMENTS (Node.js / JavaScript)
#  These are satisfied by Node.js itself — zero npm packages needed.
# ══════════════════════════════════════════════════════════════════════════════
#
#  node >= 18.0.0       (LTS recommended: 20.x or 22.x)
#  npm  >= 8.0.0        (bundled with Node.js)
#
#  Node.js built-in modules used (no install required):
#    http     — HTTP server for serving the portfolio
#    https    — HTTPS client for IBM watsonx.ai API calls
#    fs       — File system for reading index.html and assets
#    path     — Path utilities for static file resolution
#    url      — URL parsing for IBM IAM and watsonx endpoints
#
#  npm dependencies: NONE
#  The project runs with zero external npm packages.


# ══════════════════════════════════════════════════════════════════════════════
#  SECTION 2 — IBM CLOUD / WATSONX.AI REQUIREMENTS
#  External services consumed by the Agentic AI assistant
# ══════════════════════════════════════════════════════════════════════════════
#
#  IBM Cloud Account
#    URL:     https://cloud.ibm.com
#    Plan:    Lite (free) or Pay-As-You-Go
#
#  IBM watsonx.ai Service
#    URL:     https://dataplatform.cloud.ibm.com
#    Region:  us-south (default; configurable via IBM_REGION env var)
#
#  IBM Granite Model
#    Model ID:   ibm/granite-3-3-8b-instruct
#    API:        watsonx.ai Text Chat REST API
#    Version:    2023-05-29
#    Endpoint:   https://us-south.ml.cloud.ibm.com/ml/v1/text/chat
#
#  Authentication
#    Method:     IBM IAM OAuth 2.0 — API Key → Bearer Token
#    Token URL:  https://iam.cloud.ibm.com/identity/token
#    Token TTL:  3600 seconds (server caches and refreshes at 3400s)
#
#  Required Credentials (set as environment variables or in server.js):
#    IBM_API_KEY      — IBM Cloud API Key (from Manage > Access > API Keys)
#    IBM_PROJECT_ID   — watsonx.ai Project ID (from project settings)
